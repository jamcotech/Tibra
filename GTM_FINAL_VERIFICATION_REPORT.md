## 3. Ecommerce Revenue Calculation Correction (Status: PASS)

### The Issue Identified:
In GA4 Enhanced Ecommerce, the `value` parameter for `purchase` and `begin_checkout` must strictly represent the **item merchandise subtotal**, excluding shipping charges and taxes. Including shipping in `value` artificially inflates merchandise revenue and conflicts with the separate `shipping` parameter.

### Correction Implemented:
1. **`src/services/analyticsService.ts`:**
   - Updated `trackBeginCheckout(items, itemSubtotal)`:
     ```typescript
     const calculatedValue = items.reduce((sum, i) => sum + (i.price * i.quantity), 0);
     const subtotalValue = typeof itemSubtotal === 'number' && itemSubtotal > 0 ? itemSubtotal : calculatedValue;
     // Sets ecommerce.value to subtotalValue (strictly excluding shipping)
     ```
   - Updated `trackPurchase(orderNumber, itemSubtotal, items, shipping = 200)`:
     ```typescript
     const calculatedValue = items.reduce((sum, i) => sum + (i.price * i.quantity), 0);
     const finalItemSubtotal = typeof itemSubtotal === 'number' && itemSubtotal > 0 ? itemSubtotal : calculatedValue;
     // Passes value = finalItemSubtotal (item merchandise subtotal)
     // Passes shipping = 200
     ```
2. **`src/components/CheckoutPage.tsx`:**
   - Changed checkout initiation tracking from `total` to `cartSubtotal`.
   - Changed order completion tracking from `total` to `order.subtotal`.
3. **`src/components/OrderInquiryModal.tsx`:**
   - Changed order completion tracking from `order.total` to `order.subtotal`.

### Real Ecommerce Example (Duo Pack Purchase):
```json
{
  "event": "purchase",
  "ecommerce": {
    "transaction_id": "TN-1732521600000",
    "currency": "PKR",
    "value": 2600,
    "shipping": 200,
    "items": [
      {
        "item_id": "TN-PRO-030-DUO",
        "item_name": "Duo Pack (2 Bottles - 60ml Total)",
        "price": 2600,
        "quantity": 1
      }
    ]
  }
}
```
*Verification:* `value` (2,600) equals item price (2,600) &times; quantity (1). Shipping (200) is held in its own parameter. Total charged to customer = PKR 2,800.

## 4. PII Protection & Controlled Form Slugs (Status: PASS)

### The Issue Identified:
Free-text customer input (such as custom subject lines or message content) presents a risk of transmitting Personally Identifiable Information (PII) to GA4, violating Google's Terms of Service and data privacy policies.

### Correction Implemented:
1. **Removed Free-Text Subject:** Eliminated free-text subject fields from the tracking interface and analytics payloads.
2. **Enforced Controlled Inquiry Slugs:** The subject selection is strictly limited to four controlled programmatic slugs:
   - `order_status` ("Order Status / Courier Tracking")
   - `product_dosage` ("Product Dosage / Application Advice")
   - `wholesale` ("Wholesale & Retailer Inquiry")
   - `general` ("General Feedback")
3. **Zero Customer PII Sent:**
   - No customer names, phone numbers, email addresses, or physical delivery addresses are pushed to `dataLayer` or `gtag`.
   - Lead payload schema:
     ```json
     {
       "event": "generate_lead",
       "currency": "PKR",
       "form_id": "contact_form",
       "form_name": "contact_us",
       "inquiry_type": "order_status"
     }
     ```

## 5. Google Consent Mode v2 Timing & Architecture (Status: PASS)

### Execution Order in HTML:
Consent Mode v2 defaults execute in `<head>` **prior** to the Google Tag Manager container script:
```html
<!-- 1. Consent Mode v2 Default Settings (Executes BEFORE GTM) -->
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  ...
  gtag('consent', 'default', {
    'analytics_storage': analyticsVal,
    'ad_storage': marketingVal,
    'ad_user_data': marketingVal,
    'ad_personalization': marketingVal,
    'wait_for_update': 500
  });
  gtag('js', new Date());
</script>

<!-- 2. Google Tag Manager Container Snippet -->
<script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':
new Date().getTime(),event:'gtm.js'});...
})(window,document,'script','dataLayer','GTM-5Q8BQXJ6');</script>
```

### Verified Features:
- **Default Denied:** First-time visitors have all 4 parameters (`analytics_storage`, `ad_storage`, `ad_user_data`, `ad_personalization`) set to `'denied'`.
- **Interactive Controls:** Cookie consent banner offers "Essential Only", "Accept All", and "Customize Choices".
- **Dynamic Updates:** User selections trigger `gtag('consent', 'update', ...)` and push `consent_update` to `dataLayer`.
- **Persistence & Revocation:** Preferences persist in `localStorage` under `tibra_consent_state` and can be reopened or modified anytime via the "Cookie Preferences" link in the footer.
